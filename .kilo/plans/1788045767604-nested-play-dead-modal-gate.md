# Plan: Gate nested play_card against dead-modal targets (Ulitharid / Elder Brain)

## Context

The dead-modal play gate (`card_play_modal_options_viable`, `engine_c/generic_runtime.c`, declared in `engine_c/generic_runtime.h`) currently guards only **hand plays** (`engine_c/rules.c`: `engine_legal_moves` + `apply_play_card`). It fixed the IS-MCTS `vampire` crash (modal card, all options `unavailable` → no applicable move → fail-loud RuntimeError / GUI soft-lock).

Two cards play *other* cards as an effect, bypassing that gate:

| Card | Nested source | Path |
|------|--------------|------|
| Ulitharid | market row, cost ≤ 4 (`source_fragment: "play"`) | `sel_play_card` market branch → `apply_play_card_nested` |
| Elder Brain | own inner circle (`play_from_inner_circle_without_removal`) | `sel_play_card` inner-circle branch → `apply_play_card_nested` |

- `sel_play_card` (`engine_c/selection.c:864-907`) enumerates candidates with **no viability check** (only a `max_cost` filter in the market branch).
- `apply_play_card_nested` (`engine_c/actions.c:668-696`) resolves the nested `CardDefinition` and calls its effect directly — no devour check, no modal-viability check. Nested-playing an all-dead modal card calls `resolve_generic_execution` → creates an `awaiting_option` frame where every option is `unavailable` → the exact crash/soft-lock class just fixed.

Concrete trigger for tests: Ulitharid + Howling Hatred Cultist in the market row (cost 3 ≤ 4, `modal_choice`: option_1 `place_spy`, option_2 `return_spy`). With the current player at `spies_available == 0` and **no spies on the board**, both options are targetless → all-dead. (Fallback card if that fixture proves not all-dead: Cloaker — option_1 assassinate needs presence + enemy troop, option_2 needs own spy + troop at a site; dead with no presence and no enemy troops.)

## Task 2 — Defense guard in `apply_play_card_nested`

`engine_c/actions.c`: after `nested_cd` is resolved (~line 688), before `lookup_effect`:

```c
/* Defense-in-depth: sel_play_card already filters dead-modal candidates;
 * state cannot change between selection and apply. Skip (no-op), matching
 * this function's convention for unplayable nested targets. */
if (!card_play_modal_options_viable(state, player_id, nested_cd)) return state;
```

Decision made: **no-op skip** (`return state`), not NULL-rejection. Rationale: consistent with the function's existing skip convention (`!effect`, `!nested_cd`, bad selection → `return state`), and a NULL would re-introduce a fail-loud crash path in IS-MCTS for a should-never-happen branch. Consequence: on a filtered-but-still-applied card (bug), the parent sequence advances and Ulitharid's `devour_cost` still devours the market card — harmless and invisible in practice.
