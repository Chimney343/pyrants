Solution

One decision-stack module owns every pending kind: ordering, clone, save, hash and describe, plus the decision record Python reads.

  • priority rule stated once
  • Python stops reading raw pointers
  • read-before-apply ordering test retires

Does not reopen ADR-0002 (F-003 stays postponed). It gives the postponed PendingChanceState an existing frame kind to fit into, which lowers the cost of resuming that work later.
