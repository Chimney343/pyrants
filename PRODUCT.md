# Product

## Register

product

## Users

Primary users are game designers authoring board topology and board layout data for Tyrants of the Underdark. They use the board creator during content-production sessions where speed and correctness both matter.

## Product Purpose

The board creator exists to help users build and maintain valid board topology and layout JSON without hand-editing raw files. Success means users can create, validate, and save board packages quickly, with clear feedback that prevents data mismatches and broken configurations.

## Brand Personality

Simple, clear, descriptive. The product voice should feel direct, practical, and trustworthy during iterative editing work.

## Anti-references

Avoid any experience where interface text and visual state diverge. Do not use wording that suggests success when data is invalid, stale, or incomplete.

## Design Principles

1. Clarity over novelty: communicate state and required actions in direct language.
2. Workflow first: optimize feedback for the current editing task, not generic system messaging.
3. Data truthfulness: every message should map to concrete editor state.
4. Guardrails before failure: guide users to valid data entry as early as possible.
5. Fast iteration: support short edit-validate-save loops with minimal friction.

## Accessibility & Inclusion

No explicit accessibility requirements were requested. Preserve readable text labels, keyboard shortcuts, and clear non-ambiguous status messages as the baseline interaction standard.
